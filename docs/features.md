# 공개 기능 인벤토리

이 문서는 공개 저장소에 포함된 기능과 경계를 설명한다. 설계 배경과 계약은 `docs/design/`에, 사용 중심 설명은 `docs/기능소개/`에 둔다.

## 포함

### 승인과 외부효과

- 승인 생명주기: 해시 바인딩, 단일 라이브 요청, ✅/⛔ 결정, fail-closed 소비.
- 이메일·일정·작업·문서 저장·산출물 보관의 승인형 쓰기 경계.
- 민감 문서 반출과 수리 적용을 위한 내용 바인딩 및 재검증.
- 고유명사 사전 확인과 저장 목적지 라우팅. 모호한 요청은 실행 대신 질문한다.

### 스킬과 확장

- 스킬 샌드박스·검토·승인·활성화 게이트.
- 서명 검증, 격리, 이름 충돌 차단을 포함한 관리형 스킬 배포 채널.
- 활성 스킬과 공용 라이브러리 사이의 ABI 호환성 검사.
- 특정 공급자 구현을 격리하는 사이트 메일 백엔드 계약.

### 운영 안전성

- 배포 출처 검증, 스냅샷 고정, 불변 런타임 릴리스, 배포 미러 드리프트 감지.
- 배포 체크아웃의 단방향 미러 정책과 비파괴 복구 안내.
- 격리된 수리 브랜치, 검토 요청, 사람 검토 후 병합.
- 승인형 노트 쓰기, 기억 저장·정리·재배치, RAG 인제스트 경계.

## 의도적으로 제외

- 실제 배포 호스트, 주소, 포트, 계정, 자격증명, 채널 식별자, 운영 로그.
- 특정 조직이나 사이트에 종속된 메일 백엔드 구현과 그 런타임.
- 비공개 계획, 작업 티켓, 검증 증적, 개인 백로그, 시점 의존 운영 기록.
- 로컬 모델 제공·하드웨어 운영의 설치별 절차. 일반적 하드웨어 검토는 [DGX Spark 활용 검토](spark-활용-검토.md)를 참고한다.

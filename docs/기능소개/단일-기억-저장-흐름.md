# 단일 기억 저장 흐름

## 무엇을

“기억해” 요청을 한 번만 분류해 표준 저장소에 기록하고, 필요한 보조 저장은 그 결과를 재사용하는 흐름이다.

## 왜

여러 저장 경로가 각각 요청을 해석하면 같은 사실이 중복되거나 서로 다른 위치에 모순되게 남는다.

## 사용 시나리오

안정적인 선호나 결정은 표준 기억 노트 후보가 된다. 임시 상태는 영속화하지 않는다. 목적이 불명확하거나 민감도가 확인되지 않으면 저장 전에 질문하거나 거부한다.

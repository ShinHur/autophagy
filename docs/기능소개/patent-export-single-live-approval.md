# 민감 문서 반출의 단일 승인

## 무엇을

민감 문서 반출 요청마다 살아 있는 승인 메시지를 하나만 유지하고, 반출 내용이 바뀌면 새 승인으로 교체한다.

## 왜

여러 승인 메시지가 공존하면 어느 내용이 승인됐는지 알 수 없다. 민감 자료는 모호성을 실행으로 해석해서는 안 된다.

## 사용 시나리오

반출 초안이 생성되면 내용 요약과 해시가 승인 요청에 포함된다. 같은 요청을 다시 제출하면 기존 요청을 재사용한다. 내용이 달라지면 이전 요청은 소비하지 않고 새 승인 없이는 반출하지 않는다.

# 단일 라이브 승인 메시지

## 무엇을

같은 논리 요청에 대해 승인 메시지를 하나만 유지하고, 생산자와 워처가 같은 잠금과 상태를 공유하는 규약이다.

## 왜

중복된 승인 메시지는 서로 다른 내용에 대한 승인으로 오해될 수 있고, 실행을 두 번 허용할 수 있다.

## 사용 시나리오

두 요청자가 같은 작업을 동시에 제출해도 하나만 게시된다. 내용이 바뀌면 이전 미결 요청을 안전하게 교체한다. 이미 승인·거부된 요청은 워처만 소비하며 손상된 상태에서는 실행하지 않는다.

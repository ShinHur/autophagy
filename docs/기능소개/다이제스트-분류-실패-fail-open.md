# 다이제스트 분류 실패 격리

## 무엇을

요약 다이제스트의 개별 항목 분류가 실패해도 나머지 항목은 보수적 기본값으로 계속 처리하고, 실패 사실을 명시하는 정책이다.

## 왜

한 항목의 비핵심 분류 실패가 전체 알림을 멈추게 하면 중요한 정보를 놓칠 수 있다.

## 사용 시나리오

한 항목의 분류 응답이 형식에 맞지 않으면 해당 항목은 “분류 불가” 표시와 기본 분류를 사용한다. 다른 항목은 정상적으로 요약한다. 승인이나 발송 권한은 이 정책으로 완화되지 않는다.

# 스킬 배포의 단일 승인

## 무엇을

스킬 또는 발행 리비전마다 유효한 승인 메시지를 하나만 유지하는 배포 게이트 규약이다.

## 왜

여러 메시지가 같은 리비전을 가리키면 승인 상태가 갈라지고, 오래된 승인을 잘못 소비할 수 있다.

## 사용 시나리오

같은 리비전의 재요청은 기존 메시지를 사용한다. 검토 대상이 바뀌면 이전 미결 요청을 교체한다. 이미 결정된 요청은 변경하지 않으며, 상태를 읽지 못하면 배포하지 않는다.

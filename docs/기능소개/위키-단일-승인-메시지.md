# 위키 초안의 단일 승인

## 무엇을

위키 초안의 본문 해시와 승인 메시지를 일대일로 결속하고, 초안별로 하나의 라이브 승인만 유지하는 흐름이다.

## 왜

초안이 다시 게시될 때 메시지 식별자를 덮어쓰면 이전 승인과 실제 본문 사이의 연결이 사라진다.

## 사용 시나리오

초안이 생성되면 본문 해시를 포함한 한 개의 승인 요청이 게시된다. 같은 초안은 재사용하고, 변경된 초안은 새 승인을 요구한다. 이미 반응한 요청은 워처만 소비하며, 해시 불일치는 게시를 막는다.

# 일정과 조율의 단일 승인

## 무엇을

정확한 일정 등록과 참여자 조율 요청을 구분하고, 각 논리 요청에 하나의 라이브 승인만 유지하는 정책이다.

## 왜

두 경로가 같은 자연어 요청을 동시에 처리하면 서로 다른 시간의 중복 일정이 생길 수 있다.

## 사용 시나리오

정확한 시각이 정해진 요청은 일정 경로로, 참여자와 시간 범위를 조율해야 하는 요청은 조율 경로로 분류한다. 어느 쪽인지 확실하지 않으면 질문한다. 각 경로는 같은 요청을 중복 게시하거나 두 번 실행하지 않는다.

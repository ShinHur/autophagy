# 스킬 ABI 호환성 가드

## 무엇을

활성 스킬과 공용 라이브러리 사이의 호출 형태·시그니처·필수 계약을 배포 전에 점검하는 호환성 가드다.

## 왜

스킬 스냅샷이 공용 모듈에 의존하면 무관한 라이브러리 변경도 실행 중 승인 흐름을 깨뜨릴 수 있다.

## 사용 시나리오

새 공용 라이브러리를 배포하기 전 가드는 활성 스킬의 호환성을 검사한다. 경고 모드는 관측을 제공하고 엄격 모드는 불일치를 차단한다. 검사할 수 없으면 안전한 실패로 처리한다.

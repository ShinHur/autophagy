# 승인형 산출물 보관

## 무엇을

외부 보관소로 보낼 산출물을 배치로 묶고, 목록과 내용 해시를 검토 가능한 승인 요청에 결속한다.

## 왜

자동 업로드는 잘못된 파일·중복 업로드·승인 뒤 내용 변경을 숨길 수 있다. 이 흐름은 변경된 배치에 새 승인을 요구한다.

## 사용 시나리오

소유자(owner)가 보고서 묶음 보관을 요청하면 시스템은 파일 목록과 해시를 제시한다. 승인 뒤에도 목록이 같을 때만 업로드하고 완료를 알린다. 승인이 없거나 파일이 바뀌면 업로드하지 않는다.

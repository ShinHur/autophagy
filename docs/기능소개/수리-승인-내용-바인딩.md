# 수리 승인 내용 바인딩

## 무엇을

수리 승인을 패치 바이트와 변경 요약의 해시에 결속하고, 적용 직전에 같은 내용을 다시 확인하는 보호 장치다.

## 왜

패치 이름만 승인하면 승인 뒤 바뀐 바이트를 같은 승인으로 적용할 수 있다.

## 사용 시나리오

승인 요청에는 영향 파일과 변경 규모가 요약돼 표시된다. 적용 전 다시 계산한 해시가 승인 해시와 다르면 실행은 예외로 중단된다. 읽을 수 없는 패치나 표현할 수 없는 변경도 안전하게 거부한다.

# 캘린더 승인 복구

## 무엇을

캘린더 변경 승인 과정의 부분 실패를 복구하면서 같은 이벤트를 두 번 만들지 않도록 하는 흐름이다.

## 왜

승인 확인과 실행 사이의 실패를 잘못 재시도하면 중복 일정이나 위조된 승인 상태가 생길 수 있다.

## 사용 시나리오

실행 자식 단계가 실패하면 성공으로 표시하지 않고 실패를 상위로 전파한다. 일회용 승인 기록은 한 번만 소비된다. 재시도는 기존 상태와 대상 해시를 확인하며, 불일치하면 새 초안과 승인을 요구한다.

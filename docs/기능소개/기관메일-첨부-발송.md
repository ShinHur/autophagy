# 사이트 메일 첨부 발송

## 무엇을

사이트 메일 백엔드에서 첨부 파일의 이름·크기·내용 해시를 매니페스트로 검증한 뒤 승인된 메일에만 첨부하는 흐름이다.

## 왜

첨부는 본문보다 쉽게 바뀌고, 일부만 업로드된 상태가 남을 수 있다. 승인한 첨부와 실제 전송 첨부를 구별해야 한다.

## 사용 시나리오

시스템은 첨부 목록과 해시를 초안에 포함한다. 승인 뒤 서버가 반환한 첨부 식별자와 매니페스트를 다시 대조한 뒤 발송한다. 업로드 일부가 실패하거나 해시가 바뀌면 발송하지 않는다.

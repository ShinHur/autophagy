# 단일 랜딩 명령

## 무엇을

검토된 변경의 원격 반영, 배포 수렴, 활성 런타임 검증을 하나의 멱등 절차로 묶는 운영 명령이다.

## 왜

수동 단계가 나뉘면 변경은 반영됐지만 실행본은 이전 상태인 간극이 생긴다.

## 사용 시나리오

검토된 변경을 랜딩하면 절차는 기준 리비전을 확인하고 런타임을 그 리비전으로 수렴시킨다. 미러 드리프트는 별도 경고와 복구 안내로 다루며, 검증에 실패한 실행본을 성공으로 보고하지 않는다.

# 운영 메모리 재배치

## 무엇을

운영 참조로 남겨야 할 안정적 사실을 적절한 참조 노트로 옮기고, 검증이 끝난 뒤에만 원본을 정리하는 흐름이다.

## 왜

실행 중 메모리에 운영 사실이 계속 쌓이면 검색과 유지보수가 어려워진다. 이동과 삭제를 한 번의 검증 가능한 변경으로 다뤄야 한다.

## 사용 시나리오

시스템이 운영 참조 후보를 제안하면 소유자(owner)가 내용과 삭제 의도를 함께 승인한다. 새 노트가 확인되고 검색 반영까지 검증된 경우에만 원본 하나를 삭제한다. 어느 단계든 실패하면 원본은 보존된다.

# 승인형 노트 쓰기 어댑터

## 무엇을

개인 노트 저장소에 경로·제목·본문을 검증해 쓰고, 원격 반영 뒤 읽기 검증까지 수행하는 승인형 어댑터다.

## 왜

읽기용 인덱스와 쓰기 작업공간을 섞으면 검색 상태와 변경 권한이 함께 오염될 수 있다. 쓰기와 검증은 분리돼야 한다.

## 사용 시나리오

“이 내용을 개인 노트로 저장해”라고 하면 제안 경로와 본문이 제시된다. 승인 뒤 별도 쓰기 작업공간에서 반영하고 원격 내용을 다시 확인한다. 검증에 실패하면 원본을 삭제하지 않고 실패를 알린다.

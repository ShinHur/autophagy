# 사이트 메일 백엔드 통합 계약

## 무엇을

특정 사이트의 메일 구현을 교체 가능한 백엔드 계약 뒤에 두고, 저장소 소스와 실행 런타임을 분리하는 방식이다.

## 왜

공급자별 브라우저 자동화나 인증 구현을 공용 워크플로에 섞으면 이식성과 보안 검토가 어려워진다.

## 사용 시나리오

새 사이트 메일 백엔드는 계약에 맞는 읽기·초안·발송 동작을 제공해야 한다. 계약 검증이 통과한 구현만 격리된 런타임에 배치한다. 구현이나 런타임의 바이트가 일치하지 않으면 사용하지 않는다.

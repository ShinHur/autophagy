# 승인 표면의 단일화

## 무엇을

요청 유형별 승인 표면을 하나의 결정론적 정책으로 선택하고, 기록된 요청에는 당시 선택된 표면을 유지하는 규약이다.

## 왜

승인 표면을 호출자마다 제각각 고르면 소유자(owner)가 다른 위치에서 같은 요청을 승인하거나 놓칠 수 있다.

## 사용 시나리오

새 요청은 정책이 정한 표면에만 게시된다. 기존 요청은 정책이 변경돼도 저장된 바인딩에서 처리한다. 표면을 확인할 수 없으면 다른 표면으로 추측해 보내지 않고 거부한다.

# 메모리 큐레이터

## 무엇을

자체 메모리에서 중복·임시 상태·장기 판단 후보를 구분하고, 장기 보관 후보만 비파괴적으로 제안하는 도구다.

## 왜

모든 대화 상태를 영구 기억으로 만들면 품질이 떨어지고, 무단 삭제는 회복하기 어렵다.

## 사용 시나리오

큐레이터는 장기 판단 후보와 예상 절감량을 제시한다. 승인 전에는 진단만 수행하고 원본을 바꾸지 않는다. 승인된 승격이 검증되기 전이나 거부된 경우에는 원본을 그대로 둔다.

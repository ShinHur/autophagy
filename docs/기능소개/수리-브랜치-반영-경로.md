# 수리 브랜치 반영 경로

## 무엇을

수리 변경을 격리된 작업본에서 만들고, 전용 브랜치와 리뷰 요청을 거쳐 기본 브랜치에 반영하는 흐름이다.

## 왜

운영 체크아웃에서 직접 고치거나 기본 브랜치에 바로 올리면 검토·보존·복구 경계가 사라진다.

## 사용 시나리오

수리 도구는 격리된 복제본에서 재현과 회귀 검증을 끝낸 뒤 수리 브랜치로만 변경을 올린다. 검토 요청에는 수정 요약과 검증 결과만 포함한다. 소유자(owner)가 검토 후 병합하며 도구는 직접 병합하지 않는다.

# 승인 증명의 자동 재검증

## 무엇을

승인 대기 중 보조 증명의 유효기간이 끝나면, 소유자(owner)의 기존 결정을 보존한 채 같은 내용인지 확인하고 증명만 재검증한다.

## 왜

짧은 유효기간 때문에 이미 검토된 요청을 처음부터 다시 승인하게 만들면 운영 부담이 커진다. 반대로 내용이 바뀐 요청을 자동 갱신하면 안 된다.

## 사용 시나리오

검토가 지연된 배포 요청의 보조 증명이 만료되면 시스템은 동일 해시를 확인한 뒤 증명을 새로 받는다. 동시 갱신은 잠금으로 직렬화한다. 확인이 안 되면 실행을 멈춘다.

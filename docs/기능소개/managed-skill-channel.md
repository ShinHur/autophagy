# 관리형 스킬 배포 채널

## 무엇을

서명된 확장 패키지를 검증·격리·승인·활성화 순서로 배포하는 관리형 스킬 채널이다.

## 왜

확장 패키지는 실행 권한을 가진다. 출처 확인 없이 설치하거나 기존 스킬 이름을 덮어쓰면 공급망 경계가 무너진다.

## 사용 시나리오

발행자가 서명된 매니페스트를 제공하면 구독자는 서명과 이름 충돌을 확인해 격리한다. 소유자(owner) 승인 뒤에만 활성화한다. 검증 실패나 충돌은 어느 패키지도 우선하지 않고 거부한다.

# 수리 요청의 단일 승인

## 무엇을

수리 요청마다 하나의 라이브 승인만 두고, 변경된 패치는 안전하게 새 요청으로 바꾸는 흐름이다.

## 왜

고아 승인이나 덮어쓴 메시지 식별자는 어떤 패치가 승인됐는지 감출 수 있다.

## 사용 시나리오

동일 수리 요청이 반복되면 기존 미결 요청을 재사용한다. 패치 내용이 바뀌면 이전 미결 요청만 교체한다. 이미 반응한 메시지는 변경하지 않고 워처가 소비하며, 상태가 손상되면 적용을 거부한다.

# 고유명사 사전 확인 계약

## 무엇을

외부 쓰기 전에 사람·조직·대상을 여러 출처와 대조해 해석하고, 단일 고신뢰 후보만 자동 정규화하는 계약이다.

## 왜

같은 이름이나 불완전한 호칭을 잘못 해석하면 올바르게 승인된 작업도 잘못된 대상에 실행될 수 있다.

## 사용 시나리오

“김 연구원에게 일정 초안을 보내 줘”라는 요청에서 후보가 하나로 확인되면 표준 이름을 사용한다. 여러 후보가 남으면 승인 요청을 만들지 않고 대화 안에서 누구인지 묻는다.

# 대시보드 자격증명 교체

## 무엇을

로컬 대시보드의 자격증명을 비노출 방식으로 원자적으로 교체하고, 로그인 검증 실패 시 이전 상태로 되돌리는 절차다.

## 왜

자격증명 교체 중 일부 구성만 바뀌면 관리자가 스스로 접근하지 못하거나 서비스가 인증 없이 시작될 수 있다.

## 사용 시나리오

소유자(owner)가 교체를 요청하면 새 값은 보호된 입력으로만 전달된다. 시스템은 새 구성을 검증한 뒤 전환하고 로그인 검사를 한다. 검증 실패 시 기존 구성으로 복구하며 비밀 값은 출력하지 않는다.

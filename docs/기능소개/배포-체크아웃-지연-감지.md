# 배포 미러 지연 감지

## 무엇을

배포 미러가 기준보다 뒤처졌는지, 앞서 있는지, 추적 파일이 수정됐는지를 읽기 전용으로 감지하는 가드다.

## 왜

운영 미러의 드리프트를 방치하면 수렴이 막히거나 의도하지 않은 바이트가 실행될 수 있다.

## 사용 시나리오

정기 검사가 dirty·ahead·behind를 구분해 복구 방향을 안내한다. 원격을 확인할 수 없으면 확정된 정상으로 처리하지 않는다. 탐지는 파일을 고치지 않으며, 복구는 별도 검토 절차로 수행한다.

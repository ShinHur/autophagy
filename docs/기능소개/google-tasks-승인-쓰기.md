# 작업 생성 승인 쓰기

## 무엇을

외부 작업 목록에 항목을 만들기 전에 제목·기한·목록 같은 입력을 승인에 결속하고, 생성 뒤 다시 조회해 결과를 확인한다.

## 왜

작업 항목은 알림과 후속 행동을 유발한다. 승인 없는 생성과 재시도 중복을 막아야 한다.

## 사용 시나리오

소유자(owner)가 “다음 주까지 검토” 항목을 요청하면 시스템이 작성 내용을 보여 준다. 승인 뒤 한 번 생성하고 결과를 재조회한다. 거부·검증 실패·모호한 대상에서는 아무 항목도 만들지 않는다.

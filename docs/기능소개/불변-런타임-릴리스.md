# 불변 런타임 릴리스

## 무엇을

실행 중인 릴리스를 작업 체크아웃과 분리하고, 검증된 읽기 전용 릴리스 사이를 원자적으로 전환하는 구조다.

## 왜

작업본을 직접 실행하면 동시 편집과 수렴 과정이 실행 상태를 바꿀 수 있다. 불변 릴리스는 버전 확인과 롤백을 단순하게 한다.

## 사용 시나리오

새 릴리스는 별도 위치에서 검증된 뒤 활성 포인터가 한 번에 전환된다. 전환이 실패하면 기존 활성 릴리스를 유지한다. 깨진 포인터는 정상적인 부재로 취급하지 않고 수리를 요구한다.

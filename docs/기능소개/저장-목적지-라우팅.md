# 저장 목적지 라우팅

## 무엇을

문서 저장 요청의 의도·민감도·명시된 목적지를 평가해 정확히 하나의 적절한 저장 경로를 선택하는 정책이다.

## 왜

한 요청을 여러 저장소에 동시에 쓰면 중복과 접근 경계 위반이 생긴다. 모호한 요청을 임의로 공개 저장소에 두어서도 안 된다.

## 사용 시나리오

개인 노트로 지정된 요청은 개인 보관함만 대상으로 한다. 목적지가 빠진 요청은 비공개 기본값을 사용한다. 여러 해석이 가능하면 저장 전에 목적지를 묻고, 민감 자료는 전용 승인 경로를 우선한다.

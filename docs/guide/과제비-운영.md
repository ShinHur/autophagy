# 프로젝트 예산 원장 운영 가이드

이 문서는 스프레드시트 기반 예산 원장의 소유권, 갱신 주기, 스키마, 변경 감지 경계를
정의합니다. 실제 문서 ID·URL·소유자 주소·금액은 비공개 설정에만 둡니다.

## 소유권과 운영 규칙

1. 원장 값의 수정 책임은 소유자에게 있습니다. 자동화는 읽기·변경 감지·승인된 요청 초안만
   수행합니다.
2. 갱신 주기와 외부 회계 시스템 대사 주기를 운영 정책으로 명시합니다.
3. 원장은 자동화가 참조하는 단일 진실이며, 스키마 오류가 있으면 추론으로 보정하지 않고
   처리 전체를 중단합니다.

## 식별자와 접근

`BUDGET_SPREADSHEET_ID`와 필요 범위는 비공개 환경 설정으로 제공합니다. OAuth 자격증명과
원시 시트 응답은 저장소·로그·QA 증적에 기록하지 않습니다. 접근 설정은
[Google Workspace CLI OAuth 설정 가이드](w0-6-gws-oauth-setup.md)를 따릅니다.

## 권장 스키마

| 탭 | 용도 | 열 |
|---|---|---|
| 항목별 잔액 | 예산·집행·잔액 현황 | 항목, 예산, 집행액, 잔액, 최종수정 |
| 지출 이력 | 지출별 기록 | 날짜, 항목, 금액, 비고 |
| 수동 메모 | 운영 메모와 스키마 이슈 | 날짜, 메모 |

헤더 행과 데이터 시작 행은 설정으로 고정합니다. 변경 감지 전에는 헤더의 정확한 순서와
필수 열을 확인하고, 규칙 문구·공백·서식 변경이 예산 변경으로 오인되지 않도록 데이터 행만
비교합니다.

## 변경 감지와 요청

스케줄러는 읽기 전용으로 현재 스냅샷과 이전 스냅샷을 비교합니다. 차이가 발견되면
승인 가능한 요청 초안을 만들 수 있으나, 메일 발송이나 외부 시스템 변경은 기존 소유자
승인 게이트 없이는 실행하지 않습니다. 스냅샷 저장은 성공 후에만 갱신하며, 스키마 검증
실패·읽기 실패는 재시도 가능한 실패로 남깁니다.

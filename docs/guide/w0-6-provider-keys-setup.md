# 모델 제공자 자격증명 설정 가이드

모델 제공자 API 자격증명은 소유자가 발급하고, 역할별 최소 권한으로 배치하며, 값이 아닌
상태만 검증합니다. 제공자별 화면·요금·모델 이름은 바뀔 수 있으므로 공식 문서를 기준으로
현재 정책을 확인합니다.

## 자격증명 설계

- 제공자별·용도별로 분리된 키를 사용합니다.
- 키는 필요한 실행 계정의 mode `0600` 비공개 시크릿 파일 또는 비밀 관리 시스템에만 둡니다.
- 소비자 계정에는 원천 키를 복사하지 않고, 가능하면 제한된 게이트웨이 자격증명만 제공합니다.
- 비용 상한과 사용량 경보를 제공자 계정 또는 중간 게이트웨이에 설정합니다.

## 발급과 배치

1. 소유자가 제공자 대시보드에서 필요한 프로젝트·결제·권한을 확인합니다.
2. 키를 만든 직후 비밀 저장소에 입력합니다. 키 값은 명령행 인자, 로그, 채팅, 저장소에
   넣지 않습니다.
3. 중복 환경 변수나 오래된 값을 무심코 append하지 않습니다. 회전은 기존 값을 원자적으로
   교체하는 절차로 수행합니다.
4. 시크릿 파일의 소유자·권한·필수 키 이름만 출력 없이 검사합니다.

## 검증과 회전

연결 검증은 최소 요청을 사용하되 응답 본문과 인증 헤더를 버리고 HTTP 상태 또는 기능 성공
표시만 남깁니다. 실패 시 원시 오류를 공개 증적에 저장하지 말고, 제공자 대시보드의 권한·
결제·사용량 제한을 확인합니다.

유출이 의심되면 해당 키를 즉시 폐기·회전하고, 영향 범위를 조사한 뒤 필요한 서비스만
조건부 재시작합니다.

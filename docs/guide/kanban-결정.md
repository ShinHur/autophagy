# 개인 에이전트 Kanban 채택 결정

이 문서는 에이전트 작업 보드를 선택할 때의 판단 기준입니다. 특정 네트워크 주소, 계정,
하드웨어, 배포 상태는 환경별 운영 설정에서 관리합니다.

## 결정

기본안은 에이전트 런타임에 포함된 Kanban 대시보드입니다. 별도 제품은 다음 조건이 실제
검증에서 충족되지 않을 때만 폴백으로 검토합니다.

- 인증된 사설 네트워크 접근
- 모바일을 포함한 주요 화면의 사용 가능성
- 작업 상태 변경의 관측 지연 목표
- 에이전트 작업 DB와 보드의 상태 일치

## 보안과 접근

- 대시보드는 loopback 또는 지정한 사설 인터페이스에만 바인딩합니다.
- 비-loopback 바인딩에는 인증을 필수로 하고, 공개 터널·공개 DNS·라우터 포트 포워딩을
  만들지 않습니다.
- 접근 URL과 자격증명은 `<PRIVATE_DASHBOARD_URL>` 및 비공개 환경 설정으로만 관리합니다.

## 검증 기준

1. 인증 없는 요청이 거부되는지 확인합니다.
2. 데스크톱과 모바일에서 로그인, 열 이동, 카드 조회를 확인합니다.
3. API 또는 에이전트의 상태 변경이 목표 시간 안에 보드에 반영되는지 측정합니다.
4. 하나라도 실패하면 기존 보드를 공개 노출하지 않고, 대체 제품의 보안·운영 비용을 별도
   설계로 검토합니다.

폴백 제품은 하나만 선택하고, 이미지 아키텍처·인증 방식·데이터 백업·업데이트 책임을
도입 전에 검증합니다.

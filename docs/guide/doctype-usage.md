# 서류 종류 라이브러리 사용 안내

`doctype`는 승인된 예시 문서에서 서류 종류를 등록하고, 같은 종류의 새 초안을 만드는
비공개 기능입니다. 예시·승인본·초안의 본문은 private store 밖으로 내보내지 않습니다.

## 흐름

1. **등록**: 지원 형식의 예시 문서를 첨부해 서류 종류 등록을 요청합니다.
2. **개선**: 승인된 개선본을 첨부하면 기존 종류에 불변 버전을 추가합니다.
3. **초안**: 등록된 종류와 사실값을 제공하면 private 출력 경로에 초안을 만듭니다.
4. **확인**: 실행 뒤에는 이름·버전·필드 같은 본문 없는 메타데이터만 확인합니다.

지원하지 않는 컨테이너나 존재하지 않는 종류는 추측해 변환하거나 생성하지 않고 명확히
거부합니다. 생성된 초안의 검토·승인·제출은 사람이 수행하며, 이 기능은 외부 제출이나
메일 발송을 하지 않습니다.

## 보안 경계

- 예시와 초안은 `DOCTYPE_PRIVATE_ROOT` 아래의 접근 제한 저장소에 둡니다.
- 대화와 QA 출력에는 본문·첨부 경로·사실값을 붙이지 않습니다.
- 민감도 정책이 허용하지 않는 모델 경로는 fail-closed로 차단합니다.

# 에이전트 계정 프로비저닝 스크립트 가이드

`automation/provision-agent.sh <account>`는 기존 전용 Linux 계정에 에이전트 런타임과
user-systemd gateway를 반복 가능하게 구성하는 스크립트입니다. 계정 생성과 시크릿 입력은
스크립트의 범위 밖이며, 소유자 또는 승인된 운영자가 별도로 수행합니다.

## 사전조건

1. 대상 계정과 private home, linger user manager가 존재합니다.
2. 계정 소유의 시크릿 파일이 mode `0600`이고 필요한 변수 이름을 갖습니다.
3. 모델 gateway·네트워크·Discord 앱 등의 외부 의존성은 별도 절차로 준비되어 있습니다.

스크립트는 시크릿 값을 생성·복사·출력·저장하지 않아야 하며, 값이 비어 있지 않은지와 파일
권한만 확인해야 합니다.

## 수행 내용

- 계정·home·runtime 디렉터리·시크릿 파일의 소유자와 권한을 검증합니다.
- 에이전트 CLI와 런타임이 없거나 손상된 경우에만 공식 설치 절차를 실행합니다.
- 설정 파일과 systemd drop-in을 선언한 정책으로 수렴시킵니다.
- 필요한 경우에만 `daemon-reload`, enable, start 또는 restart를 수행하고 마지막에
  gateway의 active 상태를 확인합니다.

## 멱등성과 실패

정상 설치·일치하는 설정·활성 unit은 재실행에서 변경하지 않습니다. 설정이 달라질 때는
원자적 교체 뒤 해당 gateway만 조건부로 재시작합니다. 계정 또는 시크릿 파일이 없으면
명확한 오류로 종료하고, 임의의 기본 시크릿이나 계정을 만들지 않습니다.

프로비저닝 뒤 인터롭 플러그인과 승인 게이트를 배포할 때는
[외부 연구자 에이전트 온보딩 킷](onboarding-kit.md)을 따릅니다.

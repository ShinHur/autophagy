# 의사결정 디지털 트윈 사용법

의사결정 디지털 트윈은 소유자가 직접 확인한 판단·선호·원칙을 개인 위키에 쌓고, 이후
에이전트가 판단 근거로 조회하게 하는 기능입니다. 트윈은 실행 권한이 아니며 외부효과는
항상 기존 승인 게이트를 거쳐야 합니다.

## 판단 기준 등록

1. 소유자가 대화에서 선호·원칙·결정을 명시합니다.
2. 에이전트가 `decision`, `principle`, `preference` 중 알맞은 종류로 초안을 만듭니다.
3. 소유자가 ✅로 승인하면 개인 위키에 저장하고, ⛔면 폐기합니다.
4. 색인된 노트는 이후 검색과 컨설트의 근거로만 사용합니다.

직접 선언은 `stated` 출처입니다. 추론이나 관측으로 얻은 후보는 증거와 반례를 제시하되,
소유자가 승인하기 전에는 활성 규칙으로 취급하지 않습니다.

## 결정 컨설트

에이전트는 활성 위키 규칙과 관련 선례를 조회해 다음을 구분해 답합니다.

- 적용 가능한 위키 규칙
- 참고용 선례
- 충돌, 만료, 불확실성

규칙이 충돌하거나 민감한 외부효과가 포함되면 자율 실행하지 않고 소유자에게 질문합니다.
실제 결정이 내려지면 새 decision record 초안을 만들고, 이전 결정을 바꿀 때는 기존 노트를
수정하는 대신 `supersedes`로 연결합니다.

## 수명 관리

`review_after`가 지난 규칙은 권위를 한 단계 낮춥니다. 조회·백링크·정리 제안은 읽기
전용이며, 저장·활성화에는 [개인 위키](개인-위키.md)의 승인 절차가 적용됩니다.

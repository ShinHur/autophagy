# 소유자 DM FIFO와 수신확인 설계

긴 작업 중 도착한 소유자 DM이 한 요청으로 합쳐져 문맥이 섞이는 문제와, 큐에 든 메시지의
수신 상태가 보이지 않는 문제를 함께 다루는 호환 계층 설계입니다.

## 동작

- 서로 무관한 DM은 FIFO 큐에서 각각 독립된 순차 턴으로 처리합니다.
- 짧은 시간 안에 온 명시적 후속 메시지나 답장은 같은 턴에만 병합할 수 있습니다.
- 큐 한도를 넘으면 조용히 버리지 않고 해당 메시지에 실패 표시와 안내를 남깁니다.
- 물리적으로 수신한 모든 DM에는 즉시 수신확인을 남기고, 각 메시지의 처리 완료에 성공·실패
  표시를 남깁니다.

## 기록과 재시작

수신 원장은 채널 참조·메시지 참조·상태만 저장하며 본문을 기록하지 않습니다. 재시작 시
미해소 수신확인은 실패 상태로 정정하되, 원본 payload를 자동 재생하지 않습니다.

## 배포 원칙

벤더 런타임에 호환 패치를 적용해야 한다면 exact preimage 확인, 백업, 구문 검사, 멱등 적용,
명시적 revert를 제공합니다. 배포와 gateway 재시작은 기존 소유자 승인 절차를 따릅니다.
어떤 예외도 원래의 메시지 디스패치를 깨지 않도록 안전한 원래 동작으로 폴백해야 합니다.

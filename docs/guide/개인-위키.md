# 개인 위키

개인 위키는 소유자의 노트와 판단 근거를 접근 제한된 Markdown 저장소에 보관하고, 에이전트가
승인된 쓰기와 읽기 전용 검색을 제공하는 기능입니다. 위키 본문과 제목은 저장소·공개 채널·
QA 증적에 복사하지 않습니다.

## 사용 흐름

| 요청 | 동작 |
|---|---|
| 노트 저장·수정 | 초안 생성 → 소유자 ✅ 승인 → 쓰기 |
| 검색·백링크 | 읽기 전용으로 즉시 실행 |
| 정리 제안 | 오래된 노트·태그·연결을 읽기 전용으로 분석 |

취소는 ⛔입니다. 승인 확인이 불가하거나 작성자가 소유자가 아니면 쓰지 않고 fail-closed로
끝냅니다. 텍스트 확인 명령이 있더라도 리액션 승인과 같은 검증 규칙을 적용합니다.

## 노트 스키마

```markdown
---
title: "노트 제목"
tags: [tag-1]
created: 2026-01-01T00:00:00Z
updated: 2026-01-01T00:00:00Z
links: [다른-노트]
---
```

필수 키는 `title`, `tags`, `created`, `updated`, `links`입니다. 의사결정 트윈을 쓰는
노트는 [의사결정 디지털 트윈 스키마](decision-twin-스키마.md)의 선택 키를 추가할 수
있습니다.

## 저장 경계

- 위키 루트는 `WIKI_ROOT`로 지정하고(미설정 시 `~/wiki`), 디렉터리는 mode `0700`,
  파일은 mode `0600`을 강제합니다.
- 초안·감사 기록은 위키 본문과 분리된 private gate 저장소에 둡니다.
- 검색 인덱스가 위키를 소비하더라도 민감 콘텐츠를 외부 모델·공개 로그로 보내지 않습니다.
- 과거 노트 이관은 읽기 전용 사본으로 수행하고, 변환 전후 파일 수·권한만 검증합니다.

위키는 실행 권한이 아니라 판단 근거입니다. 외부효과는 위키의 `strict` 규칙이 있더라도
각 도메인의 승인 게이트를 반드시 거쳐야 합니다.

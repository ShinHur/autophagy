# 관리형 스킬 채널 가이드

관리형 스킬 채널은 발행자가 검증한 스킬을 구독자가 안전하게 가져오고, 자신의 환경에서
명시적으로 활성화하게 하는 배포 체계입니다. 구독이나 동기화만으로는 활성화되지 않습니다.

## 흐름

1. **발행**: 발행자가 소스와 매니페스트를 준비하고 서명된 태그를 만듭니다.
2. **동기화**: 구독자가 태그·매니페스트·소스 해시를 검증해 격리 구역에 둡니다.
3. **활성화**: 구독자가 격리 릴리스를 검토하고 표준 스킬 배포 승인 절차로 마운트합니다.

## 매니페스트 v1

| 필드 | 규칙 |
|---|---|
| `schema_version` | `1` |
| `publisher` | `<PUBLISHER_ID>` |
| `skill` | `managed-` 접두사, 최대 길이 제한 |
| `release_sequence` | 단조 증가하는 정수 |
| `skill_sha256` | 정규화된 소스 트리 해시 |
| `previous_sha256` | 이전 검증 릴리스와의 체인 |
| `breaking` / `migration` | 호환성 파괴 시 이관 지침 필수 |
| `revoked_digests` | 회수된 소스 해시 |

## 검증 체인

구독자는 서명 주체, 태그-매니페스트 바인딩, 스키마, 태그명, 순차성, 이전 해시 체인,
소스 해시, 회수 목록을 순서대로 확인합니다. 하나라도 실패하면 격리 구역에 넣지 않고
fail-closed로 끝냅니다.

## 운영 규칙

- 발행용 개인키는 발행자 환경에만 두고, 구독 노드에는 허용된 공개키만 배치합니다.
- 활성화에는 기존 스킬의 샌드박스·리뷰·소유자 승인·검증 절차를 모두 적용합니다.
- 일반 스킬과 관리형 스킬의 이름 충돌은 우선순위 없이 차단합니다.
- 회수된 릴리스는 자동 삭제하지 않고, 소유자가 검토한 제거 절차로 처리합니다.
- 롤백은 명시적으로 허용한 이전 순번을 다시 검증하고 활성화 절차를 처음부터 밟습니다.

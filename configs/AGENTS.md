# configs/ — 공개 정책 시드와 배포 예시

이 디렉터리의 추적 파일은 검토 가능한 불변 시드다. 런타임은 여기 파일을 수정하지 않으며, 상태와 자격증명은 `$AUTOPHAGY_RUNTIME_ROOT` 같은 보호된 체크아웃 밖 경로에 둔다.

## 파일 맵

| 위치 | 목적 |
|---|---|
| `external-effect-tools.yaml` | 외부효과 허용·차단 정책. 파싱 실패는 fail-closed다. |
| `sensitivity-rules.yaml` | 외부 전송 전의 결정론적 민감도 분류 규칙. |
| `entity-preflight.json` | 고유명사 해석 임계값과 출처 가중치 시드. |
| `peers.yaml` | 공개 가능한 협업자 레지스트리 형식. |
| `inventory.example.yaml` | 실제 배포를 담지 않는 노드·역할 스키마 예시. |
| `routing-policy.md` | 라우팅·예산·민감도 정책 설명. |
| `rag/`, `litellm-staging/` | 별도 도구 체인을 가진 선택 배포 번들. |

## 규칙

- 실제 호스트, 주소, 계정, 비밀, 채널 식별자, 고객 데이터는 커밋하지 않는다.
- 빈 파일·불량 YAML·불완전한 정책은 외부효과를 허용하는 이유가 아니라 차단 이유다.
- 런타임 모드와 생성된 캐시는 시드 파일을 덮어쓰면 안 된다.
- 예시 인벤토리는 형식만 보여 주며 실제 설치의 권위 소스가 아니다.
